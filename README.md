# Sidimar Oliveira Vianna Junior

Banco escolhido: postgresql

## Instalação automática
1. Execute npm install
2. Execute npm run configurar
3. Informe a URL do banco, e-mail e senha administrativa
4. Execute npm start
5. Site: http://localhost:3000
6. Painel: http://localhost:3000/admin

## Segurança
Nunca envie o arquivo .env. Troque a senha inicial e use HTTPS em produção.
